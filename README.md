# Cybercrime Research Summary

## Overview
This project gives us a research summary on common cybercrime threats and common cybersecurity best practices.

## Common Cybersecurity Threats

### Phishing
Phishing attacks persuade users into giving out their sensitive information like usernames, passwords, and banking details.

### Malware 
Malware includes viruses, ransomware, worms and spyware that can disrupt a system

### Unauthorized Access 
Cybercriminals exploit vulnerabilities to gain access to networks and system with the relevent authorization.

## Prevention Methods 

Use strong passwords
Deploy Multi Factor Authenication
Keep systems and software up-to-date
Back up important data consistently
